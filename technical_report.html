1. Executive Summary & Problem Formulation

Kwame Nkrumah University of Science and Technology (KNUST) hosts hundreds of events per semester across its colleges, halls of residence, faculties, and student associations (such as ECESA, CSS, Mic & Madness, and ATLAS). Historically, event promotion has relied on highly fragmented channels—predominantly ephemeral WhatsApp status updates, unstructured group blasts, and physical paper posters pasted across campus walls.

This disorganization produces severe institutional inefficiencies: rapid information decay, poor attendance forecasting, double-booked venues, and zero centralized verification of registered attendees.

EVENTWEB is engineered as a unified digital ecosystem providing:

  • A centralized, live-updating Campus Discovery Board with structured event categorization (Academic, Social, Sports, Religious, and Business).
  • An Interactive GIS Spatial Map pinning venues with custom architectural callout coordinates.
  • An automated Ticketing and Verification Pipeline delivering unique alphanumeric reference codes (EW-XXXX-XX) via email passes.
  • A verified Society Organizer Portal allowing event coordinators to upload posters to CDN storage and monitor real-time ticket capacities.

4.1 Atomic Concurrency Trigger

To prevent overselling and race conditions when multiple students register simultaneously, a PostgreSQL trigger automatically updates the event capacity counter: 

create or replace function public.handle_new_registration()
returns trigger as $$
begin
  update public.events
  set reg_count = reg_count + 1
  where id = new.event_id;
  return new;
end;
$$ language plpgsql security definer;

create trigger on_registration_created
  after insert on public.registrations
  for each row execute procedure public.handle_new_registration();

5. GIS Mapping & Geospatial Integration

EVENTWEB incorporates a dedicated Leaflet.js cartography module mapped to KNUST campus coordinates:

  • Great Hall: 6.67475 N, -1.57220 W
  • Paa Joe Stadium: 6.67780 N, -1.56950 W
  • College of Science Auditorium: 6.67350 N, -1.56650 W
  • Prempeh II Library: 6.67510 N, -1.57180 W
  • KNUST Interdenominational Church: 6.68508 N, -1.57270 W
  • Central Campus Grounds: 6.67644 N, -1.57343 W

Drafting Callout Pins: Custom markers use an architectural leader line with a category-coded indicator bar that synchronizes bidirectionally with the event list filter. Stacking context isolation (isolation: isolate, z-index: 1) prevents Leaflet map tiles from overlapping the sticky top navigation header.

6. Front-End User Experience & Interaction Design

6.1 5-Second Autoplay Hero Poster Deck

The interactive 3D poster deck implements a state machine that cycles through the latest campus flyers every 5000 milliseconds (5 seconds). If the student interacts (clicks previous/next buttons, taps a carousel dot, or drags a card), the timer automatically resets for another 5 seconds of inactivity. Opening a registration dialog pauses background rotations.

6.2 Refined 1px Modernist Hairlines

All borders across navigation, cards, input controls, chips, and modal sheets are governed by a unified token (--ew-rule: 1px). In dark mode, borders shift to #29324a to create a seamless, high-contrast visual hierarchy without visual clutter.

7. Transactional Email Pipeline (Resend)

Upon successful registration, a Supabase Edge Function running on the Deno runtime is triggered to dispatch a branded HTML confirmation email via the Resend API:

  • Unique Reference Code: Formatted as EW-XXXX-XX (e.g. EW-4471-KQ).
  • Pass Details: Society name, venue, event date, time, and tier.
  • Secure Architecture: The RESEND_API_KEY is stored strictly as a backend server secret, never exposed to client browsers.

8. Conclusion & Future Roadmap

EVENTWEB transforms campus event publicity from a fragmented, disorganized hassle into a seamless, high-engagement digital platform. Its robust architecture delivers high performance, spatial awareness, and verified administrative workflows tailored specifically for KNUST.
