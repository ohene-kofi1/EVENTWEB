EVENTWEB · VENUE MAP

Four marker treatments

All four keep the Modernist rules — flat fills, zero radius, 2px rules, no gradients or drop shadows — and none of them rely on colour alone: every marker carries a number or a label, and every one has a text alternative for screen readers. Pin 4 (Prempeh II Library) has nothing booked, so each option also shows how it handles an empty venue.

OPTION A

Poster chip

The marker is the event's own flyer, cropped to the same 2:3 as the board cards and printed grayscale per the imagery rule. Selecting one brings it to full colour. This is the map saying the same thing the hero says — every poster on campus, in one place.

OPTION B

Drafting callout

An architect's leader line: a 2px stem pinned to the exact coordinate, carrying a flat label with the venue number and a category colour bar. The most purely Modernist of the four, and the only one that names the venue directly on the map.

OPTION C

Capacity block

The square fills from the bottom in proportion to how full that venue's event is, so the map answers "where can I still get in?" at a glance. Empty venues read as a hollow outline.

CURRENT

Numbered square

What is on the map today — a flat ink square with the venue number, turning blue when selected. Correct and quiet, but it carries no information beyond position.
